# DESIGN.md

## Title

**Hybrid Editorial Web Aesthetic — Papercut × Pixel × Glitch Fashion × Organic Commerce**

---

## 1. Purpose

Use this document to instruct an AI to design a website, poster, landing page, brand system, or interface that blends the visual language of the reference images shared in this chat.

The design direction is **not** a copy of any one reference. It is a **synthesis** of all four:

1. **Papercuto** — handmade papercut typography, organic editorial composition, warm paper tones.
2. **Good / Luck** — retro pixel-script typography, grainy lo-fi image treatment, limited palette, nostalgic digital energy.
3. **Fashion** — chaotic magazine layout, oversized distorted typography, glitch/pixel masking, texture-heavy brutalist editorial styling.
4. **blume\*** — soft eco-commerce branding, oversized rounded logo typography, pill navigation, cream backgrounds, organic shapes, product-friendly layout.

The final result should feel like a carefully art-directed hybrid system:

- tactile
- expressive
- editorial
- nostalgic
- organic
- slightly experimental
- fashion-aware
- internet-native
- usable as a real interface

This is **not** a generic SaaS design system.

This is **not** a sterile startup landing page.

This is **not** simple “retro style” pasted on top of a standard layout.

It should feel like a collision between a handmade type specimen, a lo-fi poster, an underground fashion editorial, and a soft nature-driven product brand.

---

## 2. Master Creative Brief

Design the experience like an **art-directed editorial web object** that mixes:

- **hand-cut paper typography**
- **pixel-based nostalgia**
- **glitchy fashion-magazine composition**
- **soft rounded eco-branding**
- **warm tactile textures**
- **nature-forward photography**
- **bold oversized type**
- **asymmetrical but controlled layouts**

The interface should look expressive enough to feel collectible, but functional enough to work as a real product or website.

### Layer A — Tactile Foundation
A warm, soft, paper-like and nature-aware base:

- earthy greens

### Layer B — Editorial Typography
Very large type drives the hierarchy:
- chunky rounded brand type

### Layer C — Experimental Personality
Controlled disruption adds personality:
- pixelation
- collage layering

- rough edges
- irregular shapes

- printed texture

Underneath the art direction, the site must still work:
- readable text
- usable navigation

- accessible interactions

## 6. Core Design Principles

### 6.1 Typography Must Lead

Typography is not decoration. Typography is the main visual engine.

Use typography to create:
- focus
- rhythm
- scale contrast
- emotion
- brand memory

### 6.2 Imperfection Must Feel Designed

Use controlled irregularity:
- rough letter edges
- uneven shape silhouettes
- slight rotation
- non-uniform spacing
- hand-drawn outlines
- imperfect image masking

But never make it look broken, random, or amateurish.

### 6.3 Digital Meets Organic

The most important contrast in this system is:

- natural + digital
- soft + raw
- rounded + jagged
- clean commerce + messy editorial
- tactile + pixelated

Keep that tension alive.

### 6.4 Structure Under Chaos

Even when the page looks loose or expressive, there must be an invisible structure:
- grid
- alignment logic
- spatial rhythm
- consistent sizing rules
- clear hierarchy

### 6.5 Expressive, But Usable

The system should be bold and weird in the right places, but basic interactions must remain clear.

## 7. Style Spectrum

Think of the visual language as sitting between these poles:

| Soft / Organic | Raw / Editorial |
|---|---|
| rounded type | cut-paper type |
| cream space | distressed texture |
| natural photos | glitch overlays |
| product clarity | collage chaos |
| pill buttons | broken headline layouts |
| gentle nature brand | underground zine |

The best outputs should sit in the middle rather than fully collapsing to one side.

## 9. Typography System

This design language needs a **multi-voice type system**.

### 9.1 Type Roles

Use at least 3 type roles, ideally 4.

#### Role A — Hero / Brand Display
Use for:
- giant wordmarks
- hero titles
- major section headlines
- large campaign statements

This can be:
- chunky papercut type
- rounded lowercase brand type
- distorted editorial display type

Desired traits:
- strong personality
- oversized
- memorable
- not sterile
- visually dominant

#### Role B — Pixel / Retro Accent
Use for:
- selected campaign words
- badges
- secondary headings
- stylized labels
- decorative UI moments
- occasional section headlines

Desired traits:
- low-res / bitmap / pixel-script feel
- nostalgic
- intentional aliasing
- readable but obviously digital

Use sparingly. This is an accent layer, not the default content font.

#### Role C — Editorial Functional Sans
Use for:
- body copy
- descriptions
- navigation
- metadata
- labels
- small interface text

Desired traits:
- readable
- slightly warm
- modern but not too clinical
- can be neutral or softly humanist

#### Role D — Annotation / Handwritten
Use for:
- side notes
- callouts
- captions
- floating labels
- doodle text
- tiny supporting copy

Desired traits:
- handwritten
- sketch-like
- narrow or casual
- a little irregular

### 9.2 Typographic Personality Mix

The key idea is contrast.

Possible combinations:
- giant rounded logo + thin elegant subheading
- papercut headline + clean small sans metadata
- pixel word + soft photography
- distorted fashion headline + Swiss-style caption text

### 9.3 Recommended Typographic Rules

#### Large Display

```css
display: clamp(4rem, 12vw, 12rem);
line-height: 0.82;
letter-spacing: -0.04em;
```

#### Secondary Headings

```css
font-size: clamp(2rem, 5vw, 4.5rem);
line-height: 0.9;
letter-spacing: -0.03em;
```

#### Body Text

```css
font-size: 1rem;
line-height: 1.6;
max-width: 65ch;
```

#### Fine Label Text

```css
font-size: 0.78rem;
line-height: 1.3;
letter-spacing: 0.01em;
text-transform: lowercase;
```

### 9.4 Important Typography Rules

- Let headlines be huge.
- Use scale contrast aggressively.
- Do not use only one font for everything.
- Do not let body copy inherit the weirdest display style.
- Decorative typography should never make core information unreadable.
- Letterforms can overlap imagery.
- Pixel typography should remain visibly pixel-based.

## 10. Layout System

### 10.1 General Layout Character

The layout should feel editorial, not template-based.

Combine:
- full-bleed photography
- floating headline text
- asymmetrical content placement
- clean product/content rows
- occasional split-screen structures
- poster-like section breaks
- negative space
- irregular shape containers

### 10.2 Grid

Use an underlying grid such as:
- 12 columns on desktop
- 8 columns on tablet
- 4 columns on mobile

But do not make the layout feel visibly rigid.

Use the grid as a hidden skeleton.

### 10.3 Layout Modes

The system should support four compositional modes:

#### Mode A — Poster Hero
Used for:
- landing hero
- campaign header
- statement section

Characteristics:
- giant typography
- image or color field background
- floating navigation or badges
- one or two annotations
- bold focal point

#### Mode B — Specimen / Catalog Strip
Used for:
- products
- featured items
- category previews
- examples

Characteristics:
- clean repeated modules
- generous spacing
- specimen-like presentation
- minimal UI around each item

#### Mode C — Blob Content Block
Used for:
- quotes
- about text
- important copy
- editorial paragraph sections

Characteristics:
- irregular container shape
- soft organic silhouette
- large readable text
- strong contrast with surrounding texture/image

#### Mode D — Chaotic Editorial Feature
Used for:
- campaign section
- feature story
- fashion/art content
- moodboard area

Characteristics:
- layered type
- image fragmentation
- experimental overlap
- visible texture
- controlled disorder

### 10.4 Alignment Behavior

Use mixed alignment:
- centered hero logo
- left-aligned body copy
- floating labels
- offset badges
- asymmetrical product placement

Not every section needs the same alignment pattern.

- portraits with strong styling

### 12.2 Image Treatments

## 13. Texture

Texture is one of the biggest unifying tools across these references.

Use subtle but visible texture layers such as:
- paper grain
- print noise
- fabric texture
- canvas texture
- halftone-like surfaces
- faint vertical lines
- film grain
- xerox / photocopy softness
- scan artifacts

Texture should give the page materiality.

### 13.1 Texture Intensity

Use:
- light texture on most UI surfaces
- stronger texture in hero/editorial sections
- very strong texture only in feature art sections

Do not make every element equally noisy.

## 15. UI Components

### 15.1 Navigation

Navigation should feel light and graphic.

Possible treatments:
- floating pills on top of a hero image
- dark brown rounded nav items
- cream pill for active state
- tiny minimal wordmark
- sparse menu count

Avoid:
- huge transparent glass nav bars
- corporate mega-nav look
- bulky dashboard chrome

### 15.2 Buttons

Buttons can have multiple personalities depending on context:

#### Soft Pill Button
For commerce and everyday actions:
- rounded
- dark fill / cream fill
- small and neat

#### Cut-Paper Button
For editorial/promotional actions:
- irregular silhouette
- tactile visual weight
- slightly rotated hover state

#### Pixel Tag Button
For playful accent actions:
- retro feel
- low-res edge language
- used in moderation

Hover behavior should feel physical:
- tiny lift
- tiny rotation
- slight translation
- subtle shadow change

### 15.3 Product Cards

Product cards should not be standard ecommerce blocks by default.

Preferred treatments:
- product image floating in open space
- specimen-like captioning
- simple purchase control row
- minimal controls
- clean cream section
- enough whitespace

Keep them readable and purchasable.

### 15.4 Editorial Cards

Editorial cards can be more experimental:
- collage crop
- distorted heading
- image-mask interaction
- floating metadata
- rough panel structure

### 15.5 Content Blocks

Body content should live in:
- wide columns
- blob containers
- clean cream panels
- occasionally over texture backgrounds

### 15.6 Badges & Labels

Use for:
- “new”
- “featured”
- “sold out”
- “good”
- “luck”
- category notes
- small statements

They may appear as:
- hand-drawn oval bubbles
- starbursts
- pixel text chips
- tiny cream or brown pills

## 16. Hierarchy

Hierarchy should rely on **contrast**, not just font size.

Use contrast in:
- scale
- texture
- shape
- placement
- color
- type style
- density

### Example Hierarchy Pattern

1. giant expressive brand word
2. thin supporting sentence
3. image or product row
4. micro controls
5. callout text block
6. big promotional word or product bundle area

This kind of rhythm matches the references well.

---

## 17. Motion

Motion should feel tactile, not tech-demo flashy.

Use:
- slow image reveals
- gentle parallax
- paper-like slides
- tiny rotations
- hover lifts
- pixel dissolve reveals
- underline drawing
- blob scaling
- type shifting by a few pixels

### Motion Timing

```css
--motion-fast: 160ms;
--motion-medium: 300ms;
--motion-slow: 600ms;
```

### Motion Easing

```css
cubic-bezier(0.22, 1, 0.36, 1)
```

### Motion Rules

Do:
- keep it physical and subtle
- let motion support the art direction
- animate a few key moments

Do not:
- overuse blur
- use constant looping gimmicks
- use heavy 3D transforms everywhere
- make the site feel like a motion reel instead of an interface

---

## 18. Responsive Strategy

### Desktop
Lean into asymmetry, overlap, full-bleed sections, mixed composition.

### Tablet
Preserve the visual identity, but simplify overlaps and reduce visual chaos.

### Mobile
Keep:
- big type
- nature imagery
- pill nav
- blob content blocks
- expressive section headers

Stack more vertically, but do not flatten the personality into generic mobile cards.

Mobile should still feel poster-like and art-directed.

---

## 19. Accessibility

This style can be expressive **without** sacrificing accessibility.

Requirements:
- body text should have sufficient contrast
- important text should never be hidden only inside noisy effects
- controls must be clearly identifiable
- keyboard focus must remain visible
- decorative elements should not interfere with interaction
- reduced-motion support is required
- large expressive type should remain legible on mobile
- avoid using texture behind long-form copy unless contrast is high

Use expressive design responsibly.

---

## 20. Anti-Patterns

Avoid these mistakes:

- generic white-background SaaS design
- blue-purple gradient startup visuals
- default glassmorphism
- clean minimal UI with just one quirky font slapped on top
- excessive use of one single visual mode
- making the entire interface chaotic and unreadable
- too many random effects with no hierarchy
- oversaturated cyberpunk colors
- perfectly uniform card grids everywhere
- giant dashboard mockups in the hero
- corporate icon packs with no adaptation
- using pixel typography for all body text
- using papercut type for long paragraphs
- turning experimental sections into inaccessible messes
- making every section equally loud

## 25. If the Project Is a Website

If applying this style to a website, ensure these traits appear:

- a strong hero with large expressive type
- visible contrast between editorial and utility UI
- product/content modules that remain actually usable
- at least one soft organic block
- at least one more experimental typographic or pixel-based moment
- clear navigation
- breathable sectioning
- rich texture and image treatment
- a bottom section that feels like a campaign spread or ad page

---

## 26. If the Project Is a Poster or Campaign Graphic

If applying this style to a poster, emphasize:
- oversized expressive headline
- heavier texture
- more dramatic overlap
- stronger pixel or papercut treatment
- less emphasis on strict UI usability
- sharper hierarchy by scale and texture

---

## 27. Final Test

Before finalizing the design, ask:

- Does the page feel tactile?
- Does the typography do most of the emotional work?
- Is there a strong contrast between clean and rough?
- Does the design balance nature and digital energy?
- Is there evidence of papercut, pixel, editorial, and organic-commerce DNA?
- Is the layout art-directed rather than template-driven?
- Is the interface still usable?
- Is at least one section memorable at first glance?
- Does it avoid looking like a generic startup template?
- Does it borrow the references’ spirit without copying their exact content?

If the answer is “no” to several of these, the design needs more personality or better synthesis.

---

- [ ] Warm paper-like neutrals are present.

- [ ] Layouts feel art-directed, not just grid-generated.
- [ ] Natural or tactile imagery is used well.
- [ ] Texture is visible but not overwhelming.
- [ ] Buttons and navigation remain functional.
- [ ] Organic blob or irregular shape language appears.
- [ ] Experimental sections do not destroy readability.
- [ ] Product/content modules stay clear and usable.
- [ ] Mobile keeps the personality.
- [ ] The result feels like a hybrid of all references, not a copy of one.
