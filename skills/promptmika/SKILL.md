# PromptMika Pack Tools

Load domain-specific reference bundles from the PromptMika knowledge base. These packs provide curated, production-grade references for frontend design, backend engineering, security, testing, and more.

## Available Packs

| Pack | What it loads |
|------|---------------|
| `load_contract` | Skill definition + policy digest (load first) |
| `load_frontend_design` | Design philosophy, component patterns, responsive design, anti-slop rules |
| `load_design_systems` | System selection guide, index, full catalog |
| `load_horizontal_craft` | Typography, animation, color, icons, accessibility, UX laws |
| `load_backend_api` | Backend patterns, API design, integration |
| `load_security` | All 9 vulnerability catalogs |
| `load_testing` | Unit, integration, e2e, mocking patterns |
| `load_state_management` | Redux, Zustand, Jotai, signals |
| `load_systems_devops` | Architecture, DevOps, performance |
| `load_creative_writing` | Narrative, prose, style |
| `load_token_efficiency` | Token optimization, self-critique |
| `load_context_engine` | Context retention, iteration workflow |
| `load_specialized_pages` | Landing pages, portfolios, prototypes |

## Usage

Before starting work on a task, load the relevant pack. Load `load_contract` first in any new session. Use `file_offset` to page through large packs if needed.
